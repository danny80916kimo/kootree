# 樹種月份與養護參考資料維護

2026-10-24 已由管理員在 Supabase 執行 `supabase/seed_species_care_calendar.sql`，並以公開 API 唯讀驗證成功。

## 覆蓋範圍

- 326 個去除前後空白的樹種名稱均有目錄，包含行道樹與受保護樹木。資料表名稱不是植物分類學驗證結果；台／臺與空白差異在讀取時正規化，品種或近似名稱不做模糊合併。
- `tree_species_care_profiles`：326 筆。
- `tree_species_care_rules`：459 筆，其中 326 筆全年通用規則、131 筆啟用的樹種專屬參考、2 筆停用衝突規則。
- 68 個名稱有來源支持的月份參考，258 個名稱只有全年觀察，專屬月份尚待確認；不是所有樹種的專屬月份都已考證完成。
- 全年度參考規則涵蓋 69,529 棵行道樹；10 月規則涵蓋 48,206 棵。全年通用規則不列入「本月樹種專屬參考」KPI。

同一樹種可能有花期、果期及養護評估窗口多筆規則，KPI 每棵樹只計一次。來源規則不隨「真實／模擬通報」切換而改變。

## 資料表

`tree_species_care_profiles` 保存原始名稱、專家確認狀態及備註。`expert_status=pending` 表示尚未完成臺北現地專家審核；有官方參考不代表已完成現地確認。

`tree_species_care_rules` 保存：

| 欄位 | 用途 |
|---|---|
| `species_name` | 對應目錄名稱 |
| `months` | 1–12 月整數陣列；可跨年，例如 `[1,2,11,12]` |
| `rule_type` | `general` 全年例行、`flower` 花期、`fruit` 果期、`assessment` 養護評估參考 |
| `event`、`action` | 提示文字及觀察／評估事項 |
| `source_urls` | 可展開查看的 HTTPS 來源連結陣列 |
| `source_note` | 原始月份、來源限制及臺北適用性說明 |
| `evidence_level` | `general` 通用、`reference` 有來源參考、`conflict` 來源衝突、`approved` 已確認 |
| `enabled` | 是否納入月份篩選與地圖；衝突規則不得啟用 |

全年月份只是排程索引，不能解讀為法規規定每月巡查一次。未有種別月份時保留全年通用觀察，不製造看似精確的月份。實際養護與修剪須由管理單位依現地樹勢及天候評估。

## 已核對來源

1. 林業及自然保育署「臺灣原生樹木推廣及媒合平臺」：58 個名稱精確匹配的資料頁，擷取明確花果期月份；資料頁及原始月份列在 `data/maintenance/official_phenology.json`。全臺資料須依臺北現地氣候校正，不轉換成修剪月份。
2. 臺北市公園處「各式形態樹木修剪示範」：已目視核對 PDF 第 4、8、12、16、20、24 頁的歷史月曆，僅以「季節養護評估參考」呈現。歷史月曆不代表本年度施工計畫，不下達強剪指令。
3. 臺北市中正區公所「區花介紹」：木棉 2–3 月花期及約 5 月棉絮觀察。
4. 全年例行觀察以管理計畫為準；臺北市行道樹管理維護自治條例第 4 條作為行道樹巡查參考依據，受保護樹木仍須依其管理規範。

小葉欖仁的花期在農業知識入口網與高雄市公園處記載不同，且臺北歷史修剪示範文字與圖表適期不完全一致；兩筆衝突均保留來源、停用且不填固定月份。沒有以來源差異拼湊全年花期。

## 維護方式

管理員可在 Supabase Table Editor 維護這兩張資料表。一般公開 API 只有讀取權限。

- 補入新樹種時先建立目錄與全年通用觀察，再填經來源確認的專屬月份。
- 變更月份前核對物種、區域、花果期與養護用途；在 `source_note` 記錄判斷依據及審核日期，保留來源。
- 來源衝突先停用規則；確認後再更新月份、來源及證據層級，不直接把不同月份做聯集。
- 單一頁面的一般物候只能作觀察參考，不能自動轉成修剪施工時機。
- SQL 腳本可重複執行，新增缺少目錄及規則，不覆寫既有專家修改。
- 資料修改後重新啟動目前的 Dash 後台以載入最新資料。

## 程式與驗證

- `scripts/collect_care_sources.py`：唯讀蒐集樹種名稱與官方資料頁，保留來源快取。
- `scripts/build_care_calendar.py`：產生有來源的 SQL 與覆蓋清單，不自行寫入資料庫。
- `scripts/care_calendar.py`：驗證月份、全年覆蓋、來源連結、證據層級及衝突停用狀態。
- `data/maintenance/species_care_coverage.csv`：每個整理後名稱的參考月份及待確認狀態。
- `data/maintenance/cloud_validation.json`：本次雲端唯讀驗證結果。
